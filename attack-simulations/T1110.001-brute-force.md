# T1110.001 — Brute Force: Password Guessing

## Technique

**MITRE ATT&CK:** T1110.001 — Brute Force: Password Guessing
**Tactic:** Credential Access
**Tool used:** Hydra 9.7

## Objective

Simulate an attacker performing SSH password spraying against the target host, generating failed authentication events that the SSH Brute Force Detection rule catches.

## Commands Used

```bash
# Create password wordlist
cat > /tmp/passwords.txt << EOF
password
123456
admin
kali
letmein
qwerty
PASSEOF

# Run brute force against localhost SSH
hydra -l root -P /tmp/passwords.txt ssh://127.0.0.1 -t 4
```

## What This Does

- Attempts 6 common passwords against the root account via SSH
- Generates "Failed password" entries in /var/log/auth.log
- Filebeat ships these to Elasticsearch
- Kibana SSH Brute Force Detection rule fires after 5+ failures

## Result

6 login attempts, 0 valid passwords found Rule fired: SSH BRUTE Force Detection (High, Risk Score 73) Alert visible in Kibana Security → Alerts within 1 minute

## Detection

Rule query: `event.dataset:system.auth AND message:*failed* AND message:*root*`
Threshold: 5 events, All results, runs every 1 minute
MITRE: T1110.001 Brute Force: Password Guessing
